PM 視角 — 商業與使用者價值

來源：02 PRD + strategy/v2.md + ADR-005~011 對應視角：Product Manager / 策略研究者

2.1 商業假設

核心假設（單人研究專案，無外部客戶）

台股中小型股的短中期波段，受四種獨立力量（結構 / 法人方向 / 籌碼 / 動能） 同時推動時，會出現高機率的續漲行情，且該訊號可被程式化、可被歷史驗證、 可被實盤捕捉。

層維度Edge 假設
L1結構突破壓力區 → 賣壓被消化
L2法人方向外資+投信同步買 → 資金共識
L3籌碼強度主力買盤占有效成交量 > 10%
L4技術動能多均線多頭排列 + 動能指標同向

2.2 北極星指標與成功標準

2.4 技術路線競爭格局

M2 啟動前評估 4 條路線（完整對比見 ADR-005）：

路線新寫 LOC時程廠商鎖定採納
Plan A：完全自寫 Adapter Framework 6,000-8,00022 週 低 否
Plan B：FinLab-Native（深度綁定） 1,800-2,50014 週 高 否
原計畫：rqalpha + vectorbt ~5,00022 週 中 棄
Plan TQuant-Lab（採納） ~2,50017 週 中 採

選擇 TQuant-Lab 的理由

  • TEJ Zipline 台股 fork 內建 XTAI 交易日曆 + Shioaji 整合範例（節省 ~4 週工期）
  • Zipline event-driven 天然支援 M1 既有 7 訊號優先序（vectorbt 表達困難）
  • 三模式統一架構（backtest / paper / live）共用同一份 strategy code（ADR-008）
  • vectorbt 副引擎只用於 grid/WFA 最佳化（ADR-007）
  • MIT 授權，可 fork 規避 TEJ 政策風險

2.5 範圍 — 做什麼、不做什麼

✓ 在範圍內

  • 台股 TSE / OTC 個股
  • 單一四層共振策略
  • 日線（M5 視需求加分鐘線）
  • 長多單方向
  • 個人研究 + 個人實盤
  • ~100 檔 portfolio

✗ 不做

  • 美股 / 港股 / 加密幣
  • 多策略管理（M5 前）
  • 期權 / 期貨 / ETF 套利
  • 多帳戶 / 對外 SaaS
  • HFT / intraday tick-level
  • Long-short / 放空

2.6 PM 視角下的 Top 3 風險

  1. 策略無 Edge（致命） — M3 才知。商業上接受 → 砍策略而非死撐。
  2. 下市股偏誤（高） — 不處理 → IS 結果樂觀偏誤；觸發 D2 決策。
  3. FinLab 廠商風險（中） — 倒閉/漲價 → 切回 FinMind fallback（架構已隔離）。
