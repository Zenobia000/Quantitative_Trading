5.3 風險分類與處理原則

致命級（R1, R9）

無法工程性緩解，靠紀律：

  • R1 策略無 Edge → 接受 → 砍策略，不重跑
  • R9 個人中斷 → 投資文檔完整性，隨時可重啟

高影響可緩解（R4, R5, R7）

已有具體緩解路徑，需持續執行：

  • R4 下市股 → D2 漸進路線
  • R5 XQ 對拍 → 持續 100 抽樣
  • R7 FinLab 廠商 → adapter 隔離 + fallback

工程性風險（R2, R3, R6）

Sprint 0 spike 階段驗證/解決：

  • R2 M1 plug Zipline → S2 驗證
  • R3 FinLab 流量 → 架構已備
  • R6 S1/S3 fail → 退場路線

節奏性風險（R8）

長期管理，非單點修復：

  • R8 時間不夠 → 嚴格 milestone gate
  • 每 sprint 結束三問自查（達標? 暴露問題? 該停?）
