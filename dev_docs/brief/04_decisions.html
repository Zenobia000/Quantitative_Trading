D2 — 下市股資料源解決方案

D2下市股資料源
中 · 影響 M2/M3 偏誤分析
背景
FinMind 免費版無下市股清單 → 不處理會產生「生存者偏誤」（survivorship bias）→ IS 結果樂觀偏誤；TEJ 付費 NT$3-10k/月有完整覆蓋；FinLab 已付費但下市股覆蓋情形未確認。
選項
  • (A) TEJ 付費：NT$3-10k/月，完整覆蓋；總月支出再增 NT$3-10k
  • (B) TWSE 自爬：~24h 開發（WBS 3.5.2-3）；零成本但脆弱（HTML 改版會壞）
  • (C) FinLab 試試：Sprint 0 順手測 FinLab 是否含下市股
  • (D) 接受偏誤：CAGR target +3% buffer；M3 量化偏誤大小
推薦
漸進路線 (C) → (D) → (B)：Sprint 0 順手測 (C)；若不含先用 (D) 接受偏誤； M3 統計顯示偏誤過大才啟動 (B)。避免 (A) — 月支出累積過高、暫不必要。
影響
(C) OK → 省 24h 開發 + 永久解決；(D) → M3 統計可能高估 Sharpe ~5-15%；(B) → 額外 24h + 維護成本
截止
Sprint 0 結束（2026-06-08）— (C) 測試結果出來即可定

D3 — vectorbt PRO 是否購買（$20/月）

D3vectorbt PRO 訂閱
低急迫 · M3 才需要
背景
vectorbt 開源版 v1.0.0 (2026-04) 為最終整理版；PRO ($20/月) 含原生 WFA + parallelism，grid search 5-10× 加速；M3 跑 DOE 1-10 約 1000 trials × 100 檔，開源版預估 ~2h、PRO 預估 ~15min。
選項
  • (A) 買 PRO：$240/年；M3 順暢、開發體驗好
  • (B) 開源版 + 自寫 WFA：~150 LOC 自寫；長期省錢、多 ~10h 開發

推薦
選 (C) — 不預先花錢；M3 真痛了再買月費。 對單人專案 $20/月不算 painful，但「先驗證痛點再付費」是良好紀律。
影響
低 — 即便 (A) 月費 $20 × 12 = $240，相較策略潛在回報 negligible
截止

D4 — M5 雲端部署 GCP vs 本機 24x7

D4M5 雲端部署目標
低急迫 · M5 才需要
背景
M5 實盤需 24x7 運行；當前本機 PC 不便長期常開（電費 / 中斷風險）；GCP Compute Engine e2-small 月費 ~US$15-25。
選項
  • (A) GCP Compute Engine：穩定但月費 ~NT$500-800；雲端 backup → GCS 順
  • (B) 本機 PC 24x7：零月費但停電/網斷風險
  • (C) Raspberry Pi 5：一次性 ~NT$3,000，零月費、省電、可放角落
推薦
選 (A) GCP — 實盤資金安全 > 月費。GCP 也方便 backup → GCS、可遠端維運。 M4 paper trading 階段仍可從本機跑驗證。
影響
實盤穩定度 → 影響真錢；本機如斷電/網斷可能在錯時點無法執行訊號
截止
M5 前（~2027-04）

D5 — 是否引入第二位 reviewer / 協作者

D5引入外部 reviewer
低急迫 · 紀律問題
背景
當前單人多役（PM/TL/DEV/QA 全 self）；M3 PBO 結果若邊緣（如 PBO 25-35%），需獨立眼光防止 confirmation bias 把邊緣紅燈視為綠燈。
選項
  • (A) 量化朋友 review M3 結果：1-2 小時，非協作關係
  • (B) 找全職協作者：升級為小團隊（觸發 01 §1 升級條件）

推薦
選 (A) + (C) 並行：(A) 防 confirmation bias；(C) 補完整性。 (B) 暫不啟動 — 個人專案 + 策略未驗證階段，引人成本/協調 > 收益。
影響
M3 結果若被 self-deception 蒙混 → M4 paper trading 才會敗露，多燒 3 個月時間
截止
M3 結束時（~2026-11）
