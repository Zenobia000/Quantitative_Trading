## 3. 內層 Sheet 明細（16 張）— 內容與呈現方式

| 計分卡 | Sheet | 呈現方式 | 內容 |
| :--- | :--- | :--- | :--- |
| **獲利** | 歷史績效 | 折線+面積 · 熱力圖 | 累計報酬 vs 大盤（附綠色 underwater 回檔）· 可點選逐年報酬 pill（2015 −10.0% … 2026 +65.2%）· 月報酬熱力圖（年×月，紅正綠負）· 月勝率 63.3% / 平均月報酬 +1.23% |
| **獲利** | 交易 | 表格 | 逐筆進出場明細（共用，見下方交易明細） |
| **獲利** | 年度比較 | 長條 | 策略 vs 大盤逐年報酬雙組長條 + 超額報酬長條 · 贏大盤 6/12 年、平均超額 −3.88% |
| **風險** | 虧損歷史 | 回檔曲線 · 排名長條 | 回檔幅度曲線（紅策略 vs 灰大盤 underwater）· 跌幅排名 Top5（策略/大盤可切換）· 再次創高時間排名（2025 04M 664 天…） |
| **風險** | 交易 | 表格 | 同上逐筆交易表（共用） |
| **報酬比** | 夏普值 | 折線 · 長條 | 滾動夏普值（紫策略 vs 灰大盤，年/季/月切換）+ 逐年夏普比較長條 · 大於大盤 40.68%、3/11 年 |
| **報酬比** | Tail Ratio | 折線＊ | 尾部報酬比的滾動走勢（＊headless 未能單獨切換，依版面推定與夏普/波動同型） |
| **報酬比** | 策略報酬率波動 | 折線 | 滾動波動度走勢（紫策略 vs 灰大盤）· 波動度大於大盤 33.93%，可看是否長期低於大盤 |
| **報酬比** | 策略與大盤相關性 | 折線 | 滾動相關係數，現值 0.63（0 = 走勢獨立、1 = 高度正相關）· 低相關利於資產配置分散風險 |
| **勝率** | 報酬分布 | 直方圖 | 所有交易報酬直方圖（x 報酬率 −44%~+40%，y 筆數 0–45，紅虧損/紫獲利）· 5% 機率單筆虧損 >6.5% |
| **勝率** | 模擬停損 | 互動滑桿 · 散布 | 拖動停損比例（0–30%）即時重算額外盈虧與勝率變化 + 報酬率 × 最大不利偏移(MAE) 散布圖 |
| **勝率** | 模擬停利 | 互動滑桿 · 散布 | 同上停利側：拖動停利比例 + 報酬率 × 最大有利偏移(MFE) 散布圖 |
| **勝率** | 交易最大偏移 | 散布 | MFE × MAE 散布圖（y 最大有利偏移、x 最大不利偏移，含對角線）· 觀察風險報酬特性與系統性偏移 |
| **流動性** | 投資組合胃納量 | 長條+折線 | 資金規模（50萬~5億）對應安全交易佔比長條 + 平均報酬折線 · 資金達 1 百萬時 32.3% 機率買到低流動性股 |
| **流動性** | 進場當天成交量 | 長條+折線 | 成交量門檻（50張~10萬張）對應交易佔比長條 + 平均報酬折線 · 買入當天量 500 張以上佔 66.5% |
| **流動性** | 出場當天成交量 | 長條+折線 | 同上，改以出場當天成交量分桶評估賣出流動性風險 |

### 共用大表：交易明細（Shared Trade Log）

- **呈現**：可排序表格，**155 筆交易 · 16 頁**分頁
- **欄位**：名稱代號 · 報酬（↑↓ 箭頭）· 進場（日期/價）· 出場（日期/價）· 持倉%（皆 50%）· 指標 MAE / GMFE
- **互動**：可與「歷史績效」圖表連動，點特定年月即篩出該期間交易
- **可見標的**：0050 元大台灣50 · 0051 元大中型100 · 00632R 台灣50反1

## 4. 三個需登入的分頁（介面可見、功能鎖定）

### 持股 · Holdings
- 策略當期選股清單
- 未登入顯示「登入以查看選股清單」，列 A–F 資料皆「已隱藏」，僅露表格骨架預覽

### AI 優化 · AI Optimize
- 左：AI 對話工作台（「從聊天開始，打造你的投資組合」）；右：優化面板
- 功能：自動提出多個改進方向 · 一鍵回測並彙整報告 · 程式碼差異比對與追蹤 · 分支探索與效果對照
- 推薦起手式：量化多因子 · 成長股動能 · 價值投資

### 程式 · Notebook
- 內建雲端 Python Notebook 執行環境
- 功能：程式碼編輯與語法高亮 · 即時執行與輸出 · 儲存/版本/歷史 · 資料夾與檔案管理
- Kernel 控制列：核心列表 · 重啟 · 終止
