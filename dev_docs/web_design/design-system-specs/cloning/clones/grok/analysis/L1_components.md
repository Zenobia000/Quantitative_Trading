# L1 Components — grok（共用 xai）

→ **完整內容見 [`../../xai/analysis/L1_components.md`](../../xai/analysis/L1_components.md)**。

## 產品頁特有元件

| 元件 | 說明 |
|------|------|
| `capability-block` | 能力分區：line icon + 標題 + 說明段 + check 列表（Chat / Multi-agent / Search / Imagine） |
| `feature-grid-item` | 「And much more」3 欄網格，每項 = 小 icon + 短標題 + 一行說明 |
| `getstarted-step` | 「Get started」3 欄卡：Open Grok / Sign in / Start chatting，各含 CTA |
| `cta-band` | 深色圓角容器（"Building on Grok?"）+ pill CTA |
| `chat-mock` | 對話輸入框示意（圓角容器 + 輸入列 + 右側 icon button） |

按鈕：主 `Try Grok`（primary pill 黑底白字）、次 `Get SuperGrok`（ring secondary）。
