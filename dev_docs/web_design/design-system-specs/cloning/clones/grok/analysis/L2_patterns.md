## 產品頁特有 Pattern

### P-G1：Capability Stack（能力分區堆疊）
連續數個能力 section（Chat → Multi-agent → Search → Imagine），每段統一結構：line icon + 標題 + 說明 + check 列表 + 右側示意。建立「這個產品能做什麼」的節奏感。

### P-G2：Feature Grid（密集功能網格）
「And much more」：3 欄 × 多列小功能項（icon + 短標 + 一行說明），快速羅列長尾能力。比 Capability Stack 密度高。

### P-G3：Three-path Onboarding（三路徑上手）
「Get started」：3 並排卡 = 既有 app / 登入 / 開始用，各給明確 CTA。降低不同來路使用者的啟動門檻。

### P-G4：Closing CTA Band（深色收尾呼籲）
深色圓角 band（"Building on Grok?"）+ 雙 CTA，與淺色頁面形成對比、收束轉換。

> 這些 pattern 對應我方產品的「功能介紹頁」「上手引導頁」需求。
