## 🎯 判決：NO-GO

### 量化「過擬合 / 偏誤稅」
> WFA OOS Sharpe：**1.28**（大 universe，逐 fold 選參數）→ **1.07**（survivorship-aware）→ **0.63**（固定 config + 實際成本 + 完整 survivorship）。

每剝一層 degree of freedom，數字就掉一截。**1.28 → 0.63 這個落差，就是天真回測器看不到、平台量得出來的「稅」。** 之前那些漂亮數字，是「逐 fold 選參數 + 倖存偏誤 + 樂觀成本」三者疊出來的。

### Binding 原因：**成本吃掉溢酬**
動能毛溢酬 ~12%/年；月再平衡 ~40% 周轉 × 1.2% round-trip ≈ **~6%/年成本拖累** → 淨 ~6% << 18%。**台股中小型的交易成本，把月頻動能的 edge 大部分吃光了。**
