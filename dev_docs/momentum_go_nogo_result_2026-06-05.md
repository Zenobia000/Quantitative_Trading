# 動能 — Final go/no-go 結果（2026-06-05）：🔴 NO-GO

> 承 survivorship-clean 終驗（WFA OOS 1.07）。本文做最終部署判決：**剝掉每一個 researcher
> degree of freedom** — 固定 config（不逐 fold 選參數）+ 實際成本 + 完整 survivorship-clean
> universe — 看動能在「誠實的部署條件」下到底達不達標。腳本 `scripts/momentum_go_nogo.py`。

## 設定（最嚴、最誠實）
- **固定 config**：lb=252 / skip=21 / top=0.33（事前承諾，**不逐 fold 選最佳**——杜絕 PBO 抓的選擇過擬合）。
- **實際成本**：~1.2% round-trip（中小型 spread+impact，spread 攤提模式）vs 原 0.67% 假設。
- **完整 survivorship-clean universe**：補齊下市股 → **209 檔**（survivors + ~80 下市輸家）。

## 結果

| 指標 | 值 | 門檻 | 判 |

| **K1 CAGR** | **5.9%** | ≥ 18% | ❌ |
| **WFA OOS Sharpe**（固定 config，6 fold，無 re-selection）| **0.63** | ≥ 1.0 | ❌ |
| PBO（30-config landscape） | 19.7% | < 30% | ✅ |
| full-span Sharpe / slipSharpe / maxDD / holdings | 0.41 / 0.26 / 35% / 45 | — | — |

WFA OOS 逐 fold：0.94 / −0.16 / 1.90 / 1.82 / **−1.08** / 0.38（2/6 > 1.0）。

## 🎯 判決：NO-GO

**動能在誠實部署條件下，不過 18% CAGR / 1.0 Sharpe 門檻。** PBO 反而很好（19.7%，參數地景穩健），但**絕對績效不夠**。

### 量化「過擬合 / 偏誤稅」
> WFA OOS Sharpe：**1.28**（大 universe，逐 fold 選參數）→ **1.07**（survivorship-aware）→ **0.63**（固定 config + 實際成本 + 完整 survivorship）。

每剝一層 degree of freedom，數字就掉一截。**1.28 → 0.63 這個落差，就是天真回測器看不到、平台量得出來的「稅」。** 之前那些漂亮數字，是「逐 fold 選參數 + 倖存偏誤 + 樂觀成本」三者疊出來的。

### Binding 原因：**成本吃掉溢酬**
動能毛溢酬 ~12%/年；月再平衡 ~40% 周轉 × 1.2% round-trip ≈ **~6%/年成本拖累** → 淨 ~6% << 18%。**台股中小型的交易成本，把月頻動能的 edge 大部分吃光了。**

## 與四層的對比（兩者都 NO-GO，但本質不同）

| 動能 12-1 | NO-GO | **真 edge 但太弱**（淨 ~6% / Sharpe 0.63）——成本+偏誤吃光，非沒訊號 |

## 結論 & 誠實的下一步
1. **平台再次證明價值**：它擋下了一個「看起來 1.28、實際 0.63」的策略。天真回測器會部署它然後在真錢上發現只有 0.63。
2. **誠實現實**：在台股中小型、扣實際成本+反倖存，要找「18% CAGR / 1.0 Sharpe」的策略**很難**（市場夠效率、成本夠高）。動能是目前最接近的（有真溢酬），但月頻成本吃光它。
3. **可試方向（非本輪，需你定）**：
   - **降周轉**：季頻 / 加持有過濾 → 砍成本拖累（最直接，可能救活動能）。
   - **大型股動能**：spread 低很多（但前測大型 momentum 也僅 ~1.0 邊際）。
   - **多因子組合** / 換非動能 edge。
   - 或接受：台股中小型對散戶**無成本後可部署 edge**，平台轉為持續掃描 + 嚴格守門。

**動能仍是最強候選**，但**未通過 final gate**。要救它，最有希望的單一槓桿＝**降周轉（季頻）重驗**。

## 附錄：降周轉救活嘗試（2026-06-05）— 有幫助，但仍 NO-GO

新增 `MomentumConfig.rebalance`（monthly/quarterly/semiannual）；同一 final go/no-go（固定 config + 1.2% 成本 + 209 檔 survivorship-clean）跑三頻率：

| rebalance | CAGR | WFA OOS Sharpe | slipSharpe | PBO | maxDD |
|:--|:--|:--|:--|:--|:--|
| monthly | 5.9% | 0.63 | 0.26 | 19.7% | 35% |
| **quarterly** | **7.1%** | **0.86** | 0.38 | **9.7%** | 36% |
| semiannual | 6.2% | 0.69 | 0.36 | 28.5% | 37% |

**季頻是最佳**（驗證假設：降周轉砍成本拖累）——CAGR 5.9→7.1%、OOS Sharpe 0.63→**0.86**、slipSharpe 0.26→0.38、**PBO 19.7%→9.7%（地景極穩健、非過擬合）**、3/6 fold OOS>1。但 **CAGR 7.1%（<18%）、OOS Sharpe 0.86（<1.0）仍未過門檻**。

### 🎯 最終 nuanced 判決
動能（季頻）edge **真實且 robust**（PBO 9.7% 極佳、OOS Sharpe 0.86 可敬），**但太溫和**——台股中小型動能毛溢酬 ~10-12%，扣成本後 ~7%，配不上 ADR-016 的 **18% CAGR / 1.0 Sharpe** 門檻。

### 🤔 門檻適切性問題（交還使用者）
ADR-016 的 18%/1.0 是為**四層那種集中、高信念**策略凍結的。**季頻動能是分散型因子（Sharpe 0.86、PBO 9.7%、maxDD 36%）**——以分散因子標準，這其實是「真實、穩健、可投資但報酬溫和」的策略。
- **若守 ADR-016 原門檻** → momentum NO-GO，平台轉持續掃描下一個候選。
- **若認為分散因子該有不同門檻**（如 Sharpe>0.8 + PBO<10% + 正 CAGR）→ 季頻動能**達標**，值得進 paper trading 觀察。

這是策略門檻的**商業/風險偏好決策**，非工程——平台已把事實量到位（季頻動能：真、穩、但溫和）。

### 結論
- 季頻是動能最佳形態，但守 ADR-016 仍 NO-GO。
- **沒有更多免費工程槓桿**能把它推到 18% CAGR（成本+市場效率的硬牆）。
- 下一步是**使用者決策**：守原門檻轉下一候選 / 放寬門檻給分散因子收下季頻動能 / 試大型股或多因子。
