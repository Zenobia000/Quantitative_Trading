## 第二階段：單因子 IC 表（核心 80% 工作量）

### 測試矩陣

4 因子 × 6 holding periods = **24 cells**

| Holding Period | L1 結構 | L2 法人 | L3 籌碼 | L4 動能 |
| :---: | :---: | :---: | :---: | :---: |
| 1 day | IC / IC_IR / t / hit% | … | … | … |
| 3 days | | | | |
| 5 days | | | | |
| **10 days**（目標持倉） | | | | |
| 20 days | | | | |
| 60 days（時間停損） | | | | |

### 因子定義（與 v2.md 2.3 一致）

| 因子 | 計算 | 分數區間 |
| :--- | :--- | :---: |
| L1 結構 | 突破箱頂=2 / 站中線=1 / 中線下=0 | 0–2 |
| L2 法人方向 | 外資+投信同步買=2 / 單邊=1 / 同步賣=-1 / 中性=0 | -1 ~ 2 |
| L3 籌碼強度 | chip_ratio ≥ 0.10 = 2 / > 0 = 1 / < 0 = -1 / = 0 = 0 | -1 ~ 2 |
| L4 技術動能 | 三陽開泰=2 / 四大金叉=1 / 中性=0 / 熄火=-1 | -1 ~ 2 |

### 每 cell 計算

1. **IC (Spearman)**：每日 cross-sectional rank correlation，跨日平均
   ```python
   ic_t = spearmanr(factor_values_t, forward_returns_t).correlation
   IC = mean(ic_t for all t)
   ```

2. **IC_IR**：IC mean / IC std（因子 Sharpe）
   ```python
   IC_IR = mean(ic_t) / std(ic_t)
   ```

3. **t-stat**：`IC × √n`（n = 觀察日數）

4. **Hit Rate**：因子值 > 中位數的股票，未來報酬 > 0 的比例

### 通過標準（單因子）

| 指標 | 綠燈（保留） | 黃燈（觀察） | 紅燈（砍掉） |
| :--- | :---: | :---: | :---: |
| \|IC\| | ≥ 0.03 | 0.02–0.03 | < 0.02 |
| IC_IR | ≥ 0.5 | 0.3–0.5 | < 0.3 |
| t-stat | ≥ 2 | 1–2 | < 1 |
| Hit Rate | ≥ 52% | 50–52% | < 50% |

**任一因子全紅 → 該因子在策略中沒有 Edge，應砍掉或不權重。**

## 第三階段：因子相關矩陣

### 輸出

4×4 Spearman rank correlation matrix：

```
        L1     L2     L3     L4
L1    1.00   ρ₁₂   ρ₁₃   ρ₁₄
L2    ρ₁₂   1.00   ρ₂₃   ρ₂₄
L3    ρ₁₃   ρ₂₃   1.00   ρ₃₄
L4    ρ₁₄   ρ₂₄   ρ₃₄   1.00
```

### 判讀規則

| ρ 區間 | 解讀 | 行動 |
| :--- | :--- | :--- |
| > 0.7 | 高度相關，實質同一個訊號 | 合併或砍一個 |
| 0.3–0.7 | 部分獨立 | 保留但 IC 加權 |
| < 0.3 | 真獨立 | 合成有實質提升 |

### 預期高風險配對

- **L2（法人方向）vs L3（籌碼強度）**：都是大戶買賣，可能 ρ > 0.7
- **L1（結構突破）vs L4（動能多頭）**：突破時動能通常已起，ρ 可能 0.5+
- **L2（法人）vs L4（動能）**：法人進場後動能延續，ρ 可能 0.3–0.5

若 L2-L3 ρ > 0.7 → 砍一個，整個策略從「四層」變「三層」。

## 第四階段：分位數組合測試

### 方法

每個因子單獨：每日按因子值切 5 等分（Q1–Q5），計算各等分組合的前向報酬。

### 輸出

- Q5 - Q1 spread（年化報酬差）
- Q1–Q5 累積報酬曲線（視覺驗證）
- Monotonicity 檢查（Q1 < Q2 < Q3 < Q4 < Q5）

### 通過標準

- Q5 - Q1 年化報酬差 > **8%**
- Monotonicity 大致成立（容忍 Q3-Q4 微調換）

### 為什麼需要這步

IC 是 rank correlation，但 IC = 0.05 可能來自：
- 場景 A：Q5 跑贏 Q1 一大截（健康）
- 場景 B：Q3 偶爾跑贏（雜訊）

分位數測試可以區分這兩種，給出更接近實盤的 alpha 估計。

## 第五階段：合成 IC 對比（決定性測試）

### 核心驗證

**合成有沒有提升？**

### 步驟

1. 算單因子 IC：IC₁, IC₂, IC₃, IC₄
2. 算 v2.1 等權加總 score 的 IC：IC_total
3. 算 Grinold 理論上限：
   ```
   IR_upper = √(Σ IC_i² - 2×Σ(ρ_ij × IC_i × IC_j))
   ```
4. 對比 IC_total vs IR_upper vs max(IC_i)

### 判讀

| 結果 | 意義 | 行動 |
| :--- | :--- | :--- |
| IC_total > 平均 IC，接近 IR_upper | 合成有效 | 維持，但改 IC 加權 |
| IC_total ≈ max(IC_i) | 合成沒幫助，是 max factor 主導 | 直接用單因子 |
| IC_total < max(IC_i) | 合成反而傷害 | 等權加總是錯的，必改 |

### 若需改 IC 加權

```python
weight_i = IC_i / sum(IC_j for j in factors)
new_score = sum(weight_i * normalized_score_i)
```

注意：normalize 各 score 到同一尺度（z-score 或 rank），否則 weight 沒意義。

## 結果分歧情境（事先想清楚）

事先把所有可能結果與對應行動寫清楚，避免事後合理化。

| 情境 | 數據特徵 | 對 v2.x 的處理 |
| :--- | :--- | :--- |
| **A. 四因子都通過 + 合成有效** | IC 都 > 0.03，IC_total > 平均 | v2.2：改 IC 加權，進 OOS 回測 |
| **B. 某因子不通過** | 1–2 個因子 IC < 0.02 | v3.0：砍因子，重走 Part 4 |
| **C. 合成沒提升 IR** | IC_total ≈ max(IC_i) | v2.2：簡化為單因子或前 2 強因子 |
| **D. 所有因子都很弱** | IC 都 < 0.03 | **策略失效，回 Hypothesis 階段，不硬撐** |

**情境 D 是最重要的紀律考驗** — 數據說不行就停，不要因為已經投入 50h 就硬編「再調個參數」。

## 紀律規則（必讀）

### Multiple Testing 防護

**所有測試過的參數組合必須記錄**（v2.md 4.4.4 DSR N 要求）。

包含但不限於：
- 6 個 holding period 都算「6 次測試」（不是 1 次）
- 嘗試過的 normalization 方法（z-score / rank / decile）
- 不同 universe filter 的版本
- 任何「試了但沒採用」的分組方式

每多測 1 個 → DSR 被稀釋。誠實記錄是唯一防線。

### 一次跑完，不要邊測邊改

**最危險的事**：跑完發現 IC 不好，然後「再多測幾個 holding period 也許某個會過」。

**正確做法**：
1. 先在 paper 上把測試矩陣定死
2. 一次性跑完所有 24 cells
3. 看完整結果再決定下一步
4. **不在跑的過程中加 cell、改參數**

### 不要對單因子過早優化

每個因子的計算邏輯**沿用 v2.md 既定**，不要在 IC 測試階段「順手」調整因子定義。
若發現因子需要調整 → 列為 v2.2 後續工作，**重跑完整測試**。

## Linus 式總結

**這個矩陣的價值**：把整個策略的「四層共振」假設拆成 24 個可量化的 cell。
- 24 cells 全綠 → 策略本體穩，剩下都是執行細節
- 任何一個紅燈 → 砍掉那塊，比繼續加條件正確

**這份計畫的核心精神**：
- 用最笨但最清晰的方法（spearman IC）回答最核心的問題（因子有沒有 Edge）
- 把所有可能結果與行動事先寫死（避免事後合理化）
- 誠實記錄所有測試次數（避免 DSR 自欺）
