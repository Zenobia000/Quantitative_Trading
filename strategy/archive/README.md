# strategy/archive — 歷史標本

本目錄是**四層共振戰法**的歷史規格與研究模板存放處，非現行產品敘事。

四層共振經三階段驗證 + 對照診斷，證實為**負 edge、毀價值**（同股票 buy-hold 正報酬，四層做成負），已於 [ADR-023](../../dev_docs/adrs/ADR-023-momentum-no-go-hold-gate.md) 判負 edge **廢止**。

- `v2.md` — 四層共振 v2.1.0 規格書（策略消耗品，已廢止；部分程式 docstring 仍引用其指標語意作為實作對照）。
- `doe_research_template.md` — 當年為四層共振設計的 DOE 研究模板（未執行完，方法學已被平台化研究工作流 ADR-029 取代）。

現行產品定位是「個人量化 edge 驗證工廠 + 晉升管線」：策略是消耗品、審判庭是資產。詳見 `dev_docs/02_project_brief_and_prd.md`（v4.0）與 `dev_docs/INDEX.md`。
